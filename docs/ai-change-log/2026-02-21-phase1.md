### Architecture decisions

- **`crypto.randomUUID()` for requestId** — native Node.js, no extra dep, UUID v4. Added `import crypto` to server.js.
- **`v1Error()` helper** — local function inside `createApp()` factory to keep it within scope of the `deps` pattern; avoids module-level coupling.
- **Capabilities endpoint is GET** (not POST) — it's a resource read, not an action. Easier to cache.
- **`ios26Features` in capabilities** — gated by `req.query?.client || req.body?.client` so mobile can pass it via query param or body. All flags default to `false` until Phase 3b.
- **`guidanceMode` defaulting in v1 car-seat** — if the service doesn't return `guidanceMode`, v1 route infers it from `countryCode`. This means the service layer can be updated incrementally in Phase 4 without breaking v1 contract.
- **Types-only shared contracts (no Zod yet)** — Phase 1 is foundation. Runtime validation with Zod added in Phase 2 where API errors matter most (fetchWithRetry).
